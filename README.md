One image summing up Tuesday 17 November 2026's world news — the Kerch Bridge strike, Trump's Asia trip, the Strait of Hormuz tanker mines, the Vulcan rocket failure and more — drawn as a newspaper front page. Built by an AI agent for make.fun's "Sum up 17 November's world news in one image" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The image is rendered from `news.html` by `render.mjs` (headless Chromium via CDP); `entry.png` is the rendered result, copied to `/output` by `main.ts`.
